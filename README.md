### 🚀 Featured Projects

#### 🎓 Master's Thesis
* **[Joint Image Deblurring and Out-of-Stock Detection](https://github.com/palma-or/Joint-Image-Deblurring-and-Out-of-Stock-Detection-for-Retail-Shelf-Monitoring)**  
  Developed a robust out-of-stock (OOS) detection pipeline resilient to motion blur for retail shelf monitoring. The system combines a joint GAN (**Blur2Blur**) with a **YOLO26n** architecture and was successfully validated on an out-of-distribution test set of dynamic frames captured by a **Pepper robot**.
  
#### 🤖 Robotics & Autonomous Vehicles
* **[Guardian of the Mall (Pepper Robot Assistant)](https://github.com/palma-or/Pepper-Mall-Guardian-ROS)**  
  A ROS-based AI robotic system that transforms the Pepper humanoid robot into an interactive mall assistant. Integrates real-time video analytics (people, face, and Ekman emotion detection) with a **RASA-powered voice chatbot** to answer complex environmental queries using natural language.
* **[CARLA Autonomous Driving Agent](https://github.com/palma-or/CARLA-AutonomousDrivingAgent)**  
  An enhanced autonomous driving agent developed in the **CARLA simulator**. Implements modular behavioral managers to safely navigate complex urban scenarios, including overtaking static obstacles, handling intersection right-of-ways, and dynamic interactions with pedestrians and bicycles using PID and Stanley controllers.

#### 👁️ Computer Vision & Deep Learning
* **[Dynamic Pedestrian Attribute Recognition and Tracking](https://github.com/palma-or/Pedestrian-Attribute-Recognition-and-Tracking)**  
  A real-time tracking and attribute recognition pipeline. Integrates **YOLOv8n** for detection, **HybridSORT** with OSNet for tracking, and a custom **ResNet34 Multi-Task Network** to classify pedestrian attributes (gender, accessories). Enhanced the training dataset using VILT and VQA.

#### 🛡️ AI Security
* **[Face Recognition System Security Evaluation](https://github.com/palma-or/Face-Recognition-Security-Evaluation)**  
  An in-depth adversarial machine learning study using the **ART library**. Evaluated the robustness of a FaceNet model against attacks like FGSM, BIM, PGD, Carlini-Wagner, and DeepFool. Analyzed attack transferability to ResNet50 and implemented a binary classifier defense mechanism that improved system accuracy by 39%.

#### 💻 Software Engineering 
* **[AutomationApp](https://github.com/palma-or/Task-Automation-App)**  
  A Java/JavaFX desktop application based on the trigger-action paradigm (IFTTT). Built using the MVC architecture, Chain of Responsibility pattern, and multi-threading for background rule evaluation. Developed following strict **Agile/SCRUM** methodologies.
